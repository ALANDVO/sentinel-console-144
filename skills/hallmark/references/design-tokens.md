# Design Tokens

This skill validates design tokens against curated allowlists and bans sloppy patterns.

## Token Linting

Validates design tokens against curated allowlists.

## Ban List Enforcement

Hard bans on sloppy patterns:
- Untyped colors
- Inconsistent radii
- Manual px values

## Claude Code Integration

Works in your editor context without requiring separate tooling or context switching.

## CI Integration

Fail builds on slop with `sentinel lint`.
